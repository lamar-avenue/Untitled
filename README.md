# Untitled

This is a code bundle for Untitled. The original project is available at https://www.figma.com/design/IlD82xqXLk5Et1XJiJNHok/Untitled.

## Running the code

Run `npm i` to install the dependencies.

Run `npm run dev` to start the development server.

## Deploy to GitHub Pages

This repository deploys automatically to GitHub Pages via GitHub Actions on every push to `main`.

- Workflow file: `.github/workflows/deploy.yml`
- Production URL: https://lamar-avenue.github.io/Untitled/

The Vite `base` is set to `/Untitled/`, so local development and GitHub Pages paths both resolve correctly.
